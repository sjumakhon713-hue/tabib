Табиб — Android-барнома (APK)

Ҳамаи файлҳои барнома дар дохили APK ҳастанд (app/src/main/assets/www).
Барнома бе интернет кор мекунад; танҳо ҳуруф (fonts) аз интернет бор мешаванд.

Роҳи 1 — GitHub (бе компютери пурқувват):
  1. Дар github.com репозиторийи нав созед ва ҳамаи ин файлҳоро бор кунед.
  2. Ба ҷадвали "Actions" гузаред — "Build APK" худкор оғоз мешавад.
  3. Пас аз 5–8 дақиқа дар поёни саҳифа "Tabib-APK"-ро зер кунед — APK зеркашӣ мешавад.

Роҳи 2 — Android Studio:
  File > Open > ин папка > Build > Build App Bundle(s) / APK(s) > Build APK(s).

Тағйир додани барнома: файли app/src/main/assets/www/index.html-ро иваз кунед ва дубора бор кунед.
